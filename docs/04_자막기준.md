# 04. 자막 기준 — 확정된 스타일

정의 파일: `editor/src/1010wh-editor/styles.ts`(프리셋), 값: `editor/src/1010wh-editor/Root.tsx`.
크기는 모두 **1080x1920 기준 px**. 긴 줄은 자동으로 화면 폭(1000px)에 맞게 줄어듦.

## 1. 큰 원칙(사용자 피드백으로 확정)
1. **자막은 말하듯이.** 기본 자막은 애니메이션 없이 말 단위(0.9~1.9초)로 툭툭 바뀜. 화려한 연출은 리액션·강조에만.
2. **빨강 최소화.** 글자를 빨강으로 칠하지 않음. 강조는 "흰 글자 + 빨간 글로우".
3. **최신 뷰티 쇼츠 톤.** 얇은 고딕 기본 + 명조/손글씨 포인트 + 글로우. 두꺼운 고딕·둥근 손글씨 남발 금지.
4. **위치는 중앙에서 살짝 아래**(삼등분 기준 y=1220 → 영상 칸의 아래쪽, 전체 화면 약 64%). 맨 위 검정 띠엔 제목.
5. 레퍼런스가 있으면 **수치까지 그대로**(폰트·크기·테두리·그림자). 원 폰트가 유료(산돌 등)면 가장 가까운 무료 폰트로 바꾸고 그 사실을 기록.

## 5. 연출(anim)
| id | 동작 |
|---|---|
| none | 즉시 표시(기본 말자막 — 레퍼런스와 동일) |
| pop | 통 튀어나오기(spring 0.6→1) |
| shake | 튀어나오며 10프레임 흔들림 |
| talk | 한 글자씩 톡톡(자막 길이 60% 안에 다 나옴, talkSpeed 0.06초/자) |
| type | 타이핑 |
| wave | 물결 |
| fade | 블러인 |
| **sparkle(샤랄라, 현재 기본)** | 블러인으로 나타나고 분홍 글로우가 일렁임. 글자 위·옆 8곳에서 분홍·흰 ✦✧와 ♡가 28프레임 주기로 차례로 반짝(보조자막은 안 가림) |
| starfield(별무리) | CapCut 별무리식: 글자가 왼→오로 드러나고(마스크, 22프레임), 그 앞을 따라 흰 별·빛가루 60개가 퍼졌다 사라짐. 이후 흰 별 14개가 계속 반짝. 사용자가 비교 후 하트 버전으로 원복 → 선택지로만 남김 |
기타: `zoom`(영상 1→1.12 확대), `flash`(3프레임 흰 번쩍), `labels`(Before/After — Playfair Italic 120px, 그림자+보라/분홍 글로우).

## 6. 줄바꿈 규칙
- 큰 글씨(90px 이상)는 10자, 작은 글씨는 18자 넘으면 가운데 띄어쓰기에서 두 줄. `{ }` 안은 나누지 않음.
- 어색하면 문구에 `\n`을 직접 넣음(예: "무쌍이\n왕홍메이크업 받으면").
- 제주명조는 `?!` 폭이 넓어 문장부호만 Gowun Batang으로 자동 대체.
