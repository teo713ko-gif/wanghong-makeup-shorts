# 03. 컷 편집 — 자막 기준 컷 구성

## 원칙
1. **자막 하나 = 컷 하나.** 자막의 원본 구간(a~b)에서 그 문장에 맞는 화면을 가져온다.
2. **자막 읽을 시간만큼만 보여준다.** 출력 길이 `d = clamp(0.4 + 0.068 × 글자수, 0.9초, 1.9초)`.
3. 원본 구간이 더 길면 **빨리 감기**(배속 = 구간/d). 3배속을 넘으면 가운데 3d 길이만 잘라 3배속.
4. 원본 구간이 더 짧으면 d를 구간 길이로 줄임(느리게 늘이지 않음).
5. 훅·비포애프터는 고정 길이: 첫 자막 1.3초, "쌍꺼풀이 생긴다구?!?!" 1.6초, 비포-애프터 2.3초.
6. 검정 구간에 걸린 자막은 다음 화면을 빌림(docs/02 표).
7. 자막 없는 구간(7.5~28.4초)은 생략.

## 구성(출력 78.47초)
| 출력 | 내용 | 비고 |
|---|---|---|
| 0~1.3 | 쌩얼 셀카 + "무쌍이 / 왕홍메이크업 받으면" | 훅 1 |
| 1.3~2.9 | 애프터 눈 클로즈업 + "쌍꺼풀이 생긴다구?!?!" | 훅 2(3초 안에 결과 공개), 확대·번쩍 |
| 2.9~5.2 | 비포/애프터 나란히 + Before/After 라벨 | 훅 3 |
| 5.2~ | 클렌징 → 쌩얼 → 원하는 사진 → 단계 1~9 메이크업 | 단계 라벨로 진행 표시 |
| ~66 | 완성 → 헤메 12만원 → 자연광 | |
| 66~72 | "오히려 푸슬푸슬…" + 길거리·눈 클로즈업 몽타주 | 원본 170.5~173(1.5배), 318~321(1.5배) |
| 72~75.6 | 미소 셀카 + "여러분 선택은?" (보조: 비포 vs 애프터) | 원본 420~423.5 |
| 75.6~78.5 | **비포/애프터 나란히 2.9초**, 라벨만 크게 | 원본 4.5~7.4. 처음과 이어져 반복 재생 유도 |

## 베이스 영상 두 종
| 파일 | 용도 | 처리 |
|---|---|---|
| `base.mp4` 1080x1920 | 전체화면 레이아웃 | 화면 영역을 세로로 꽉 채우게 확대 후 가운데 자름. 비포/애프터·사진 컷은 흐린 배경 위에 잘림 없이 |
| `base_square.mp4` 1080x1096 | **삼등분 레이아웃(기본)** | 화면 영역을 잘림 없이 축소. 전 컷 7% 확대 후 아래 기준 자르기로 카메라 시간표시 제거 |
- 길거리 컷(원본 149초 이후)은 `z:1.1` 확대로 시간표시를 가림.
- 인코더: macOS `h264_videotoolbox`. 다른 OS는 `libx264`로 바꿔도 됨.

## 데이터 흐름
```
captions_src.json (자막·원본 시각)
   └─ plan.py ─→ cuts.json (s,e,배속,fit,z)  +  captions_out.json (출력 시각 자막, v1~v5용)
                    ├─ build_base.py        → base.mp4
                    └─ build_base_square.py → base_square.mp4
editor/src/1010wh-editor/Root.tsx (편집기 자막: 출력 시각, 역할, 스타일)
```
- 편집기 자막(Root.tsx)은 v5의 captions_out을 `make_root2.py`로 변환해 만든 뒤 Studio에서 손본 값. 컷을 바꾸면 Root.tsx의 `start/dur`와 `durationInFrames`도 같이 맞춰야 함.
