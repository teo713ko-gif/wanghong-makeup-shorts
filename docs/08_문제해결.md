# 08. 문제 해결 — 실제로 겪은 것

| 증상 | 원인 | 해결 |
|---|---|---|
| Whisper 결과가 30초마다 "감사합니다." | 원본이 무음(-91dB)이라 생기는 환각 | `volumedetect`로 먼저 확인. 무음이면 사용자 자막 사용 |
| ffmpeg `No such filter: 'drawtext'` | 설치된 ffmpeg에 drawtext 없음 | 글자는 전부 Remotion에서. 분석 이미지는 번호 없이 만들고 순서로 판단 |
| 장면 모음이 이상하게 보임(검정·일부만) | 세로 캔버스 안 정사각 영상 + 461초 이후 검정 | `cropdetect`로 영역 확인 후 `crop=2160:2192:0:824` |
| 길거리 컷에 "10/06 16:48:15" 노출 | 카메라 시간표시가 영상에 박힘 | 전체화면: z 1.1 확대 후 아래 기준 자르기 / 삼등분: 전 컷 7% 확대 |
| 스틸 렌더 `Frame NaN is not finite` | zsh는 `$F`를 띄어쓰기로 나누지 않음 → 프레임 목록이 한 덩어리로 전달 | `${=F}` 또는 숫자를 직접 나열 |
| 렌더 중 `ENOSPC: no space left on device` | Remotion이 렌더마다 public 폴더를 통째로 복사한 임시 번들을 남김(101개, 46GB) | `$TMPDIR/remotion-webpack-bundle-*` 삭제. 렌더 스크립트에 끝나면 `fs.rmSync(serveUrl)` 추가(편집기 스크립트에 적용됨) |
| `Folder name can only contain a-z…` | Remotion `<Folder>` 이름에 한글 불가 | `wanghong-makeup` |
| 제주명조 `?!?!` 사이가 벌어짐 | 제주명조 문장부호 폭이 넓음 | 문장부호만 Gowun Batang으로 렌더 |
| 손글씨 자막 줄바꿈 "받으/면" | 글자 폭 계산 없이 자동 줄바꿈 | `whiteSpace: nowrap` + 가운데 띄어쓰기 기준 두 줄 + 폭 맞춰 축소, 필요하면 `\n` 직접 |
| Dokdo 글자 사이가 너무 넓음 | 폰트 기본 자간 | 자간 -0.09em, 줄간 0.9 |
| 샤랄라 반짝이가 보조자막을 가림 | 반짝이 위치가 글자 아래까지 | 위·옆에만 배치 |
| 산돌클라우드 폰트 다운 불가 | 로그인·구독 필요 | 무료 유사 폰트로 대체하고 기록 |
| 저장소에 영상 못 올림 | GitHub 파일당 100MB 제한 | 원본·베이스·렌더는 work/(git 제외), 720p 미리보기만 포함 |
