# 05. 자막 편집기 — 사용과 확장

Remotion Studio를 편집기로 씁니다. 자막 값(문구·시각·역할·스타일)은 zod 스키마로 정의돼 있어 Studio 오른쪽 Props 패널에 드롭다운으로 나옵니다.

## 실행
```bash
cd editor && npm install && npm run editor   # http://localhost:3010
```
왼쪽 `wanghong-makeup` 폴더:
- **WanghongEditor** — 영상 편집 화면
- **StyleCatalog** — 모든 프리셋을 같은 문장으로 비교(`qa/스타일카탈로그.jpg`)

## Props 구성
| 항목 | 설명 |
|---|---|
| layout | thirds(삼등분, 기본) / full(전체화면) |
| title, titleStyle | 위 띠 제목(줄바꿈 `\n`)과 스타일 |
| bottomText | 아래 띠 문구 |
| **roles** | 역할별 `style`·`anim`·`scale` — 여기서 바꾸면 그 역할 자막이 전부 바뀜(“이 역할엔 이 예시”) |
| emphStyle | `{단어}` 강조 스타일 |
| subPos, subStyle | 보조자막 위치(below/above)·스타일 |
| captions[n] | text, sub, role, style(auto=역할 따름), emph, anim(auto), pos, scale, zoom, flash, labels, step, start, dur |
| showSteps, stepStyle, stepScale, stepPos | 단계 라벨 |
| talkSpeed | talk 연출 글자 간격(초) |
| custom | style을 custom으로 고른 자막의 폰트·크기·색·테두리·글로우·가로비율 직접 조절 |
수정 후 **Save** → `src/1010wh-editor/Root.tsx`에 기록됨.

## 렌더
```bash
node render-1010-wanghong-editor.cjs v6                 # work/최종/v6/왕홍메이크업_v6.mp4
```

- 출력 폴더는 환경변수 `WH_PROJECT`로 바꿀 수 있음(기본 `../work`).
- zsh에서 프레임 목록을 변수로 넘길 땐 `${=F}`처럼 나눠서 넘길 것(docs/08).

## 새 스타일 예시 추가하는 법(“예시 주면 그대로”)
1. 예시 캡처를 `references/폰트예시/`에 넣는다.
2. 측정: 글자 높이·폭으로 1080 기준 크기 환산(캡처 폭이 W면 ×1080/W), 테두리 두께·색, 그림자 방향·번짐, 글로우 색, 위치(y/높이).
3. 폰트 찾기: 후보 폰트로 같은 문장을 렌더해 캡처와 나란히 비교(이 작업에서 쓴 방식 — Pillow로 비교 이미지 생성).
4. `styles.ts`의 `PRESETS`에 한 줄 추가:
```ts
my_style: {label: '[예시이름.png] 설명', font: 'FamilyName', size: 80, color: '#fff', stroke: 3, strokeColor: '#000', glow: 'rgba(255,110,190,.8)', glowSize: 1, shadow: '0 3px 6px rgba(0,0,0,.4)', scaleX: 0.9, letterSpacing: '-0.02em', lineHeight: 1.1},
```
5. 새 폰트면 `public/1010wh/`에 파일을 넣고 `FONTS`에 `['FamilyName', '파일명']` 추가.
6. Studio 새로고침 → 드롭다운·StyleCatalog에 나타남. 역할(`roles`)에 지정하거나 자막별 `style`로 지정.

## 새 연출 추가
`Editor.tsx`의 `CharAnim`(글자 단위)이나 `CaptionView`(자막 전체)에 분기를 추가하고 `styles.ts`의 `ANIMS`에 이름을 등록.

## 파일
| 파일 | 역할 |

| styles.ts | 프리셋·폰트 목록·연출 이름·역할·위치 값 |

| make_root.py / make_root2.py | v5 자막 데이터 → Root.tsx 최초 생성(make_root2 = 역할 기반) |
