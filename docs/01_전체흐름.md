# 01. 전체 흐름 — 처음부터 그대로 재현하기

이 문서 순서대로 하면 같은 영상이 나옵니다. 각 단계의 "왜"는 02~08 문서에 있습니다.

## 0. 준비물
| 항목 | 내용 |
|---|---|
| 원본 | `왕홍메이크업_1차.mp4` (2160x3840, 30fps, 830.9초, 음성 무음) → `work/원본/` |
| 사용자 자막 트랙 | `references/왕홍메이크업_자막.mp4` (CapCut에서 자막만 검정 배경으로 뽑은 190.8초 영상) |
| 도구 | ffmpeg(drawtext 필터 없어도 됨), python3 + numpy + pillow, node 20+ |
| Remotion | `editor/` 에서 `npm install` (remotion 4.0.523 고정) |

## 1. 원본 분석 (docs/02)
```bash
bash pipeline/analyze_source.sh work/원본/왕홍메이크업_1차.mp4 work/분석
```
확인할 것:
1. 음성: `mean_volume -91dB` → **무음**. 말소리 자막을 만들 수 없음 → 사용자 자막 트랙이 내레이션 역할.
2. 검정 구간: **461초 이후 끝까지 검정**(실제 화면은 0~461초). 35.1~36.4, 40.5~42.3, 47.9~50.1, 132.6~136.4초도 짧은 검정.
3. 화면 영역: 세로 캔버스 안에 정사각에 가까운 영상(4K 기준 `crop=2160:2192:0:824`).
4. 장면 전환 시각(`scenes.txt`) = 카메라 클립 경계.
5. 장면 모음(`sheet5s.jpg`)으로 흐름 파악: 0~16초 비포/애프터 맛보기 → 28초~ 세안·쌩얼 → 33~136초 메이크업 과정 → 136초~ 완성·길거리·몰·눈 클로즈업 → 461초 끝.

## 2. 사용자 자막 판독
```bash
python3 pipeline/extract_caption_track.py references/왕홍메이크업_자막.mp4 work/자막판독
```
- 자막이 바뀌는 시각 60개 + 구간별 글자 이미지(`cap_read_*.png`)가 나옴.
- **자막 트랙 시각 = 원본 시각**(장면 전환과 ±0.2초 일치). 그래서 자막 구간이 곧 그 문장에 맞는 원본 화면.
- 글자를 읽어 `pipeline/captions_src.json`에 적는다(이미 완성본 있음). 화면 밖으로 잘린 문구 7개는 추정 복원(`chk: true`).

## 3. 컷 구성 → 베이스 영상 (docs/03)
```bash
python3 pipeline/plan.py            # captions_src.json → cuts.json(+출력 시각 자막). 이미 최종 cuts.json 있음
python3 pipeline/build_base.py editor/public/1010wh/base.mp4                 # 전체화면 1080x1920
python3 pipeline/build_base_square.py editor/public/1010wh/base_square.mp4  # 삼등분용 1080x1096
```
- `plan.py`를 다시 돌려도 현재 `cuts.json`과 똑같이 나옴(엔딩 2.9초 연장 포함, 검증함).
- 결과 길이 78.47초(2354프레임).

## 4. 자막 편집기에서 자막 얹기 (docs/04, docs/05)
```bash
cd editor && npm run editor   # http://localhost:3010 → wanghong-makeup › WanghongEditor
```
- `src/1010wh-editor/Root.tsx`에 현재 확정값(58개 자막, 역할별 스타일, 삼등분 레이아웃)이 들어 있음.
- 역할별 스타일은 Props의 `roles`에서, 자막 하나는 `captions[n].style/anim`에서 바꾼다. Save 하면 Root.tsx에 저장.

## 5. 렌더 (덮어쓰기 금지)
```bash
cd editor
node render-1010-wanghong-editor.cjs still 20 911 2290   # 확인용 스틸 → work/검수/editor_stills/
node render-1010-wanghong-editor.cjs v6                  # → work/최종/v6/왕홍메이크업_v6.mp4 (+Root 스냅샷)
```
- 같은 버전 폴더가 있으면 멈춤 → 새 버전 번호 사용.
- 무음 원본이라 무음 오디오 트랙만 붙임. BGM은 업로드 앱에서 넣음.

## 6. 검수
- 1.4초 간격 장면 모음:
```bash
ffmpeg -i work/최종/v6/왕홍메이크업_v6.mp4 -vf "fps=1/1.4,scale=135:240" work/검수/q_%03d.jpg
ffmpeg -pattern_type glob -i "work/검수/q_*.jpg" -vf "tile=14x4" -frames:v 1 work/검수/sheet.jpg
```
- 보는 것: 자막 줄넘김(단어 중간 끊김), 얼굴·눈 가림, 카메라 시간표시 노출, 반짝이가 보조자막 가림, 빨강 과다.
- 장면 모음만 본 것과 전편 재생을 구분해서 기록(`project/버전목록.md`).
